# 阴影实现指南

## 当前状态

您的渲染器已经实现了完整的光照系统，但**阴影功能尚未实现**。虽然代码中已经预留了阴影相关的字段（如 `LightComponent::castShadows`、`shadowMapSize` 等），但实际的阴影渲染逻辑还没有实现。

## 实现阴影的基本步骤

要实现阴影功能，需要完成以下几个步骤：

### 1. 创建阴影贴图着色器

首先需要创建用于渲染阴影贴图的着色器。这个着色器只需要输出深度值。

**创建 `shaders/shadow_depth.vert`：**
```glsl
#version 450 core

layout(location = 0) in vec3 aPosition;

uniform mat4 uLightSpaceMatrix;  // 光源空间的视图投影矩阵
uniform mat4 uModel;

void main() {
    gl_Position = uLightSpaceMatrix * uModel * vec4(aPosition, 1.0);
}
```

**创建 `shaders/shadow_depth.frag`：**
```glsl
#version 450 core

// 对于方向光，只需要深度值，片段着色器可以为空
// OpenGL会自动使用gl_Position.z作为深度值
```

### 2. 修改主着色器以支持阴影采样

需要在 `material_phong.vert` 中输出光源空间位置：

**修改 `shaders/material_phong.vert`：**
```glsl
// 在输出变量中添加
out vec4 FragPosLightSpace;

// 在main()函数中添加uniform
uniform mat4 uLightSpaceMatrix;  // 光源空间的视图投影矩阵

// 在main()函数中计算
FragPosLightSpace = uLightSpaceMatrix * modelMatrix * vec4(aPosition, 1.0);
```

**修改 `shaders/material_phong.frag`：**
```glsl
// 在输入变量中添加
in vec4 FragPosLightSpace;

// 添加阴影贴图uniform
uniform sampler2D uShadowMap;
uniform bool uHasShadowMap;
uniform float uShadowBias;

// 添加阴影计算函数
float CalculateShadow(vec4 fragPosLightSpace) {
    if (!uHasShadowMap) {
        return 0.0;  // 没有阴影贴图，返回0（无阴影）
    }
    
    // 执行透视除法，将裁剪空间坐标转换为NDC坐标 [-1, 1]
    vec3 projCoords = fragPosLightSpace.xyz / fragPosLightSpace.w;
    
    // 转换到 [0, 1] 范围
    projCoords = projCoords * 0.5 + 0.5;
    
    // 检查是否在阴影贴图范围内
    if (projCoords.x < 0.0 || projCoords.x > 1.0 ||
        projCoords.y < 0.0 || projCoords.y > 1.0 ||
        projCoords.z < 0.0 || projCoords.z > 1.0) {
        return 0.0;  // 在阴影贴图范围外，不产生阴影
    }
    
    // 从阴影贴图中采样深度值
    float closestDepth = texture(uShadowMap, projCoords.xy).r;
    
    // 当前片段的深度
    float currentDepth = projCoords.z;
    
    // 检查当前片段是否在阴影中
    // 使用bias避免阴影失真（shadow acne）
    float shadow = currentDepth - uShadowBias > closestDepth ? 1.0 : 0.0;
    
    return shadow;
}

// 在EvaluateDirectionalLight函数中应用阴影
vec3 EvaluateDirectionalLight(int index, vec3 norm, vec3 viewDir, vec3 baseDiffuse) {
    vec3 direction = normalize(-uLighting.directionalDirections[index].xyz);
    vec3 lightColor = uLighting.directionalColors[index].rgb * uLighting.directionalColors[index].a;

    float diff = max(dot(norm, direction), 0.0);
    vec3 diffuse = diff * baseDiffuse * lightColor;

    vec3 reflectDir = reflect(-direction, norm);
    float spec = pow(max(dot(viewDir, reflectDir), 0.0), uShininess);
    vec3 specular = spec * uSpecularColor.rgb * lightColor;

    // 计算阴影（仅对第一个方向光应用阴影）
    float shadow = 0.0;
    if (index == 0 && uHasShadowMap) {
        shadow = CalculateShadow(FragPosLightSpace);
    }

    return (diffuse + specular) * (1.0 - shadow);
}
```

### 3. 创建阴影渲染系统

需要创建一个新的系统或扩展现有系统来处理阴影贴图的渲染。

**基本流程：**

1. **创建阴影贴图Framebuffer**
   - 使用深度纹理作为附件
   - 分辨率通常为 1024x1024 或 2048x2048

2. **计算光源空间矩阵**
   - 对于方向光：创建正交投影矩阵
   - 对于点光源：创建透视投影矩阵
   - 对于聚光灯：创建透视投影矩阵

3. **渲染阴影贴图**
   - 绑定阴影贴图Framebuffer
   - 使用阴影深度着色器
   - 渲染所有需要投射阴影的物体（`castShadows == true`）

4. **在主渲染中使用阴影贴图**
   - 将阴影贴图绑定到纹理单元
   - 设置光源空间矩阵uniform
   - 在片段着色器中采样阴影贴图

### 4. 计算光源空间矩阵（方向光示例）

```cpp
// 计算方向光的光源空间矩阵
Matrix4 CalculateLightSpaceMatrix(const Vector3& lightDirection, 
                                  const Camera& camera,
                                  float shadowDistance) {
    // 计算场景的包围盒（基于相机视锥体）
    // 这里简化处理，使用固定的包围盒大小
    
    float orthoSize = shadowDistance;  // 正交投影的大小
    float nearPlane = 0.1f;
    float farPlane = shadowDistance * 2.0f;
    
    // 光源位置（在场景中心上方）
    Vector3 lightPos = camera.GetPosition() + lightDirection * shadowDistance;
    
    // 创建光源的视图矩阵（看向场景中心）
    Vector3 target = camera.GetPosition();
    Vector3 up = Vector3::UnitY();
    
    Matrix4 lightView = MathUtils::LookAt(lightPos, target, up);
    
    // 创建正交投影矩阵
    Matrix4 lightProjection = MathUtils::Orthographic(
        -orthoSize, orthoSize,
        -orthoSize, orthoSize,
        nearPlane, farPlane
    );
    
    // 光源空间矩阵 = 投影矩阵 * 视图矩阵
    return lightProjection * lightView;
}
```

### 6. 启用阴影

在您的示例代码中启用阴影：

```cpp
// 在创建光源时启用阴影
LightComponent sunLightComp;
sunLightComp.type = LightType::Directional;
sunLightComp.color = Color(1.0f, 0.97f, 0.9f, 1.0f);
sunLightComp.intensity = 1.2f;
sunLightComp.enabled = true;
sunLightComp.castShadows = true;  // 启用阴影
sunLightComp.shadowMapSize = 2048;  // 阴影贴图分辨率
sunLightComp.shadowBias = 0.005f;  // 阴影偏移
world->AddComponent(sunLight, sunLightComp);
```

## 常见问题

### 阴影失真（Shadow Acne）

**问题**：物体表面出现条纹状的阴影失真。

**解决**：增加 `shadowBias` 值，或在着色器中使用更智能的bias计算：

```glsl
float bias = max(0.05 * (1.0 - dot(norm, lightDir)), 0.005);
float shadow = currentDepth - bias > closestDepth ? 1.0 : 0.0;
```

### 阴影边缘锯齿

**问题**：阴影边缘有明显的锯齿。

**解决**：使用PCF（百分比接近过滤）：

```glsl
float CalculateShadowPCF(vec4 fragPosLightSpace) {
    // ... 前面的代码 ...
    
    float shadow = 0.0;
    vec2 texelSize = 1.0 / textureSize(uShadowMap, 0);
    for(int x = -1; x <= 1; ++x) {
        for(int y = -1; y <= 1; ++y) {
            float pcfDepth = texture(uShadowMap, projCoords.xy + vec2(x, y) * texelSize).r;
            shadow += currentDepth - uShadowBias > pcfDepth ? 1.0 : 0.0;
        }
    }
    shadow /= 9.0;
    
    return shadow;
}
```

### 阴影太远或太近

**问题**：阴影只覆盖部分场景。

**解决**：调整光源空间矩阵的投影范围，确保覆盖相机视锥体。
